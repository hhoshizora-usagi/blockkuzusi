# ブロック崩し - 全部入り 仕様書

## 概要
ブラウザで動作するブロック崩しゲーム。隠しキャラによるパワーアップ要素を搭載した「全部入り」仕様。
1つのHTMLファイルで完結し、GitHub Pagesでそのまま公開可能。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| ファイル名 | `index.html` |
| ファイル形式 | 単一HTML（CSS・JS内蔵） |
| 対応環境 | PC（Chrome/Firefox/Edge/Safari）・スマホ・タブレット |
| 画面サイズ | レスポンシブ対応（最大460×680px、端末に合わせて自動調整） |
| 外部依存 | なし（ライブラリ不要） |
| 公開方法 | GitHub PagesにHTMLファイルを置くだけでOK |

## ゲームルール

### 基本ルール
- パドルでボールを跳ね返し、画面上部のブロックをすべて壊すとクリア
- ボールを落とすとライフが1減る
- ライフが0になるとゲームオーバー

### パラメータ

| 項目 | 値 |
|------|------|
| ブロック配置 | 5行 × 8列（計40個） |
| 初期ライフ | 3 |
| 隠しキャラブロック数 | 5個（ランダム配置） |
| 初期ボール速度 | 3.5（スケール係数適用） |
| 最大ボール速度 | 7.0（スケール係数適用） |
| パワーアップ効果時間 | 9秒（540フレーム） |

### スコア

| ブロック行（上から） | 色 | ポイント |
|------|------|------|
| 1行目 | 赤 (#e94560) | 50点 |
| 2行目 | オレンジ (#f97316) | 40点 |
| 3行目 | 黄色 (#facc15) | 30点 |
| 4行目 | 緑 (#22c55e) | 20点 |
| 5行目 | 青 (#3b82f6) | 10点 |

- ハイスコアは `localStorage` に保存（キー: `bkHi`）
- ブラウザを閉じても記録が残る

## 隠しキャラ & パワーアップシステム

### 隠しキャラブロック
- 40個のブロックのうち5個がランダムで「隠しキャラ入り」になる
- 見た目は通常ブロックと少し異なる：**微かにキラキラ光る**（✨マーク）
- 壊すとパワーアップアイテムが落下する
- 壊した瞬間、白い大量パーティクルが発生

### パワーアップ一覧

| アイテム | アイコン | 色 | 効果 |
|------|------|------|------|
| マルチボール | ⚡ | 紫 (#d946ef) | ボールが2個追加される |
| ワイドパドル | ↔️ | シアン (#06b6d4) | パドルが1.5倍に広がる（9秒間） |
| スコア2倍 | ×2 | ゴールド (#eab308) | ブロックのポイントが2倍（9秒間） |
| スローボール | 🐢 | ライムグリーン (#84cc16) | ボール速度が0.6倍に低下（9秒間） |

### パワーアップの挙動
- 壊したブロックからカプセルが落下する
- パドルでキャッチすると効果発動
- キャッチできずに画面下に落ちると消滅
- 効果中は画面左下に残り時間を表示

## 演出・エフェクト

### パーティクル
- ブロック破壊時：ブロックの色で12個のパーティクル
- パドルでボール反射時：シアン色で4個
- 隠しキャラ発見時：白色で18個（追加）
- パワーアップキャッチ時：アイテム色で14個
- パーティクルは重力の影響を受けて落下し、フェードアウトする

### ボールの見た目
- 紫～白のグラデーション球体
- 光るエフェクト（グロー）
- 紫色のトレイル（残像）が10フレーム分表示

### パドルの見た目
- 紫～ピンクのグラデーション
- ピンク色のグローエフェクト

### 背景
- ダークネイビー (#0d0d1a → #12122a)
- 薄いグリッド線で奥行き感

### サウンド（Web Audio API）
- パドル反射：短いスクエア波（520Hz）
- ブロック破壊：トライアングル波（680Hz）
- パワーアップ取得：サイン波の和音（880Hz + 1100Hz）
- ライフ減少：低音のノコギリ波（200Hz）
- クリア時：3連のサイン波メロディ（660→880→1100Hz）

## 技術仕様

### レンダリング
- Canvas 2D APIで描画（60fps）
- ゲーム用キャンバスとエフェクト用キャンバスの2層構造
- `roundRect` メソッドでブロック・パドルの角丸

### レスポンシブ対応
- 画面サイズに合わせて自動スケーリング
- スケール係数 `S = W / 460` で全要素のサイズを計算
- タッチイベントの `passive:false` でスクロール防止

### 物理演算
- ボールの反射角はパドルの当たり位置で変化（端に当たるほど角度がつく）
- ブロックとの衝突は重なり量で反射方向を決定（最小重なり方向に反射）
- ブロック破壊ごとにボール速度が微増（+0.015*S/破壊、上限7*S）

### データ保存
- `localStorage` でハイスコアを永続化
- キー名: `bkHi`

## 公開方法（GitHub Pages）

1. GitHubにリポジトリを作成（例: `my-games`）
2. `block_breaker.html` をリポジトリにアップロード
3. Settings → Pages → Source を `main` ブランチに設定
4. 数分後に `https://ユーザー名.github.io/my-games/index.html` でアクセス可能
