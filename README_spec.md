# ブロック崩し - 全部入り 仕様書

## 概要
ブラウザで遊べるブロック崩しゲーム。スマホ・PC両対応。
1つのHTMLファイル（index.html）で完結、外部依存なし。

## 基本ルール
- ボールを打ち出してブロックを全部壊したらクリア
- パドル操作：マウス / タッチ（スマホ）
- ブロック配置：5行 × 8列（40個）
- 色ごとにポイントが違う（上の行ほど高得点）
- ボール速度はブロックを壊すごとに少しずつ上がる
- ライフ：3個。全て失うとゲームオーバー
- スコア & ハイスコアはlocalStorageで保存

## 隠しキャラ & パワーアップ
40個のブロックの中に5個の「隠しキャラブロック」がランダムに配置される。
隠しキャラブロックは微かに光っている（シマーエフェクト）。
壊すとパワーアップアイテムが落ちてくる。

### パワーアップ一覧
- ⚡ マルチボール：ボールが+2個追加
- ↔ ワイド：パドルが1.5倍に広がる（10秒）
- x2 スコア 2倍：得点が2倍（10秒）
- 🐢 スロー：ボール速度が60%に低下（10秒）

## 演出
- ブロック破壊時：パーティクルエフェクト
- 隠しキャラ発見時：白色パーティクル大量放出
- パドルバウンス時：水色パーティクル
- ボールにグローエフェクト
- アクティブパワーアップは画面左下に残り時間付きで表示
- クリア時：「おめでとう」オーバーレイ
- ゲームオーバー時：スコア表示オーバーレイ

## 画面構成
- 上部：スコア / ライフ(♥) / ハイスコア
- 中央：ブロックエリア
- 下部：パドル & ボール
- 左下：アクティブパワーアップ表示

## 技術仕様
- ファイル形式：単一HTMLファイル（外部依存なし）
- 描画：HTML5 Canvas (2D)
- 角丸描画：arcToによる手動実装（roundRect API不使用で広いブラウザ互換性）
- Canvas：1枚構成（480x640固定）
- データ保存：localStorage (ハイスコア)
- 対応ブラウザ：Chrome, Safari, Firefox, Edge (最新版)
- 対応デバイス：PC, スマホ, タブレット

## 公開方法
GitHub Pagesにindex.htmlをアップロードすればURLを共有するだけで遊べる。
